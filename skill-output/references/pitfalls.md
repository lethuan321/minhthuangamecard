# Pitfalls and limits

These are source-derived risk explanations. The current five files do not include historical failing revisions, screenshots or a runtime reproduction, so none is presented as a proven past incident.

| Topic | Symptom to watch for | Cause / evidence boundary | Source-backed mitigation |
|---|---|---|---|
| Lenis reduced-motion default | Smooth scroll appears inactive with reduced motion enabled | script.js initLenis comments say the library can bypass smoothing, but the external Lenis implementation was not read. Its upstream default is unverified. The same comment incorrectly mentions .6s while executable options use 1.2s. | initLenis explicitly sets respectReducedMotion:false, duration:1.2; initMotion keeps 1.2 on preference change. Record this policy honestly. Do not claim it respects reduced motion for 3D. |
| Strict-mode block functions | ReferenceError on a function only declared inside try/block when a catch/outer scope tries to call it | index.html is a module. createScene has several functions inside its construction try. There is no failing out-of-block call demonstrated here. | createScene declares shared ownership/cleanup state outside try and performs catch cleanup directly there. Keep helper uses in their defining block; return the controller inside that block. Local mobileMonitor remains inside try with its users. |
| Canvas alpha with bloom | Dark output rectangle, mismatched fog edge or incorrect compositing | createScene begins with alpha:true and clear alpha 0, but full composer output needs a deliberate background. The files do not prove which prior rectangle was caused by alpha versus CSS. | createDesktopFX updateGlobals sets clear alpha 1 and the fog color to the same dark theme color. OutputPass ends the chain; rollbackConstruction restores original clear state. style.css separately removes content overlay rectangles. |
| Safari blur prefix | Header/dialog blur missing on a Safari version needing the prefix | Browser-specific failure is not reproduced by this extraction. The source includes both declarations. | style.css .header.is-scrolled and dialog::backdrop pair -webkit-backdrop-filter with backdrop-filter. Final body.webgl-ready override disables both on content surfaces. Never restore blur to a whole reading section. |
| Showpiece gated to desktop | Small screen has CSS cards but no ribbon/scene replacements | The name createDesktopFX and old comments are misleading; current gating is by explicit URL flags. | index.html ensureDesktop skips only off/lite/min plus lifecycle state, enabled checks fx=min, and style.css final showpiece mobile rules reserve anchor space. Keep width-dependent layout, not width-dependent showpiece eligibility. |
| Per-frame DOM writes | Style work/jitter dominates the animation budget | Several per-frame rect reads and some DOM writes still exist; there is no measured performance guarantee. | index.html flushHUD writes dataset at most every 250ms and only changed values; updateSteps compares rounded emphasis values; script.js initCursor batches to one RAF. Keep denomination textures built once. Do not claim all per-frame DOM work was eliminated. |
| Shared materials | Recoloring a pricing object changes an unrelated ring; temporary foil survives exit | Shared material identity makes property changes affect all users. No historical reproduction is supplied. | index.html pricing grid uses own(soft.clone()); desktop faces/bodies are cloned; savedMaterials/setCardMode restore originals; shock rings have individual clones. Share immutable materials, clone mutable per-object state and release owned clones. |

## Additional source limits not promoted as reusable patterns

- index.html priceLabels enumerates a fixed list rather than deriving every saving label from the catalog. Some current savings do not have an entry. The skill reuses dynamic public data, not this enumeration; it does not claim all badges are complete.
- updateSteps writes --station-emphasis, but style.css does not consume that property. Do not promise this write produces a visual emphasis effect.
- loadDesktopModules is called eagerly even for explicit reduced/off flags; those flags control scene construction, not all network loading.
- style.css contains older rules overridden by later patches. This skill copies the final effective patterns, not the patch layering as an architectural recommendation.
- CSS reduced-motion rules disable animations/transitions, but JavaScript intentionally keeps 3D and Lenis running. No general motion-accessibility certification is implied.
- No independent contrast measurement, browser screenshots, CPU-throttle run or real-device test was performed for this documentation extraction. The acceptance checklist is for future implementations.
- No formal spacing-token scale, actual private settlement implementation, verified payment backend, broader design process or design alternatives were added; none is implemented in the permitted source.
